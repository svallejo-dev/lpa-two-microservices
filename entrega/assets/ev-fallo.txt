1. Apagando el Servicio de Usuarios...
   Servicio de Usuarios DETENIDO.

2. Intentando crear un pedido de ese mismo usuario valido
   HTTP/1.1 503 Service Unavailable
   retry-after: 5
   {"error":"user_directory_unavailable","message":"No se pudo verificar el usuario porque el Servicio de Usuarios no respondio (The operation timed out.). El pedido no fue creado; reintente mas tarde."}
   Tardo 5 s: el timeout acota la espera en lugar de colgar la peticion.
   503, no 400: el problema no son los datos del cliente. Y el pedido NO se guardo.

3. Lo que SIGUE funcionando mientras Usuarios esta caido
   GET /orders  -> [HTTP 200]
   Las lecturas de pedidos no dependen de Usuarios: el fallo esta acotado, no tumba el servicio entero.

4. Diagnostico automatico
   {"status":"degraded","service":"orders-service","dependencies":{"database":"ok","users_service":"unreachable"}}
   La sonda dice exactamente cual de las dos dependencias fallo.

5. Restaurando el Servicio de Usuarios...
   Servicio de Usuarios ARRIBA.
